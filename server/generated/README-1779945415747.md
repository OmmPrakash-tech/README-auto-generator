# Meeting Summarizer AI with RAG Capabilities

## 🚀 Project Title
**Meeting Summarizer AI**

## ✨ Description
The `Meeting Summarizer AI` is an advanced, AI-powered tool designed to streamline post-meeting workflows by automatically transcribing, summarizing, and enabling intelligent Q&A over meeting audio. Leveraging state-of-the-art Natural Language Processing (NLP) and Retrieval-Augmented Generation (RAG) techniques, this project transforms raw audio into concise summaries and an interactive knowledge base, making meeting insights easily accessible and actionable.

## 🌟 Features

*   **Automated Audio Transcription:** Converts meeting audio files (e.g., `.wav`) into accurate text transcripts using advanced speech-to-text models. Includes audio processing capabilities like chunking for efficient handling of long recordings.
*   **Intelligent Summarization:** Generates concise, coherent summaries of meeting discussions, highlighting key decisions, action items, and main topics.
*   **Key Information Extraction:** Identifies and extracts crucial entities, topics, and potentially sentiment from the meeting content, providing structured insights.
*   **Retrieval-Augmented Generation (RAG):** Enables users to ask natural language questions about the meeting content and receive relevant, context-aware answers by retrieving information from the transcribed and processed text.
*   **Vector Store Integration:** Efficiently stores and indexes meeting data and embeddings in a vector database (`vector_store.py`) to power fast and accurate RAG queries.
*   **Modular Architecture:** Designed with separate components for transcription (`transcriber.py`), audio processing (`audio_processor.py`), summarization (`summarizer.py`), information extraction (`extractor.py`), and RAG (`rag_engine.py`) for easy maintenance, scalability, and independent development.
*   **Configuration Management:** Uses `settings.json` for easy configuration of API keys and model parameters.

## 🛠️ Installation

Follow these steps to set up the project locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Swain-Sanjay/meeting-summarizer-ai.git
    cd meeting-summarizer-ai
    ```

2.  **Set up a Python virtual environment (recommended):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
    ```

3.  **Install dependencies:**
    ```bash
    pip install -r Requirements.txt
    ```

4.  **Configure API Keys:**
    Create a `settings.json` file in the root directory (if it doesn't already exist) and populate it with necessary API keys for your chosen LLM provider (e.g., OpenAI, Anthropic, Google AI) and transcription service (e.g., OpenAI Whisper API).

    Example `settings.json`:
    ```json
    {
      "OPENAI_API_KEY": "your_openai_api_key_here",
      "ANTHROPIC_API_KEY": "your_anthropic_api_key_here",
      "GOOGLE_API_KEY": "your_google_api_key_here",
      "TRANSCRIPTION_MODEL": "whisper-1", // or specify a local model path if applicable
      "LLM_MODEL": "gpt-4o", // or 'claude-3-opus-20240229', 'gemini-1.5-pro' etc.
      "EMBEDDING_MODEL": "text-embedding-ada-002" // or other embedding model
    }
    ```
    *Ensure you replace placeholder values with your actual API keys.*

## 🚀 Usage

To process a meeting audio file and leverage its summarization and RAG capabilities:

```bash
python main.py --audio_file "How a Middle Class Boy Built NVIDIA From Nothing to $4 Trillion.wav"
```

Replace `"How a Middle Class Boy Built NVIDIA From Nothing to $4 Trillion.wav"` with the actual path to your meeting audio file.

The script will perform the following actions:
1.  Process and transcribe the audio file.
2.  Generate a summary of the meeting.
3.  Ingest the transcript into the vector store for RAG.
4.  Potentially enter an interactive loop allowing you to ask questions about the meeting content.

**Example Interactive Q&A (after initial processing):**

```bash
# (Assuming main.py initiates an interactive session or prompts)
> Ask a question about the meeting: What were the main topics discussed?
> (AI responds with a summary of the main topics from the transcript)

> Ask a question about the meeting: What was mentioned about NVIDIA's early challenges?
> (AI retrieves relevant passages and synthesizes an answer based on the RAG engine)

> Ask a question about the meeting: Who was mentioned as a key figure in the company's growth?
> (AI provides information about key figures mentioned in the transcript)
```
