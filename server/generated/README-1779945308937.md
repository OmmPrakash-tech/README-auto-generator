## Description

The **AI-Powered Meeting Summarizer** is a robust and intelligent tool designed to streamline the process of summarizing audio recordings, particularly focused on meetings, lectures, or long-form discussions. It leverages state-of-the-art speech-to-text transcription, a powerful Retrieval-Augmented Generation (RAG) engine, and sophisticated summarization techniques to provide concise, accurate, and insightful summaries, along with the capability to answer questions about the content.

This project aims to convert raw audio into structured, queryable, and summarized text, significantly reducing the time and effort required to review lengthy audio content.

## Features

*   **Advanced Audio Transcription:** Converts spoken language from audio files into highly accurate text using modern speech recognition models.
*   **Intelligent Summarization:** Generates comprehensive and coherent summaries of the transcribed content, highlighting key discussion points and decisions.
*   **Retrieval-Augmented Generation (RAG):** Integrates a RAG engine to enhance summarization quality and enable intelligent Q&A over the meeting content by leveraging an organized vector store of information.
*   **Key Information Extraction:** Identifies and extracts crucial entities, topics, and actionable items from the transcribed text.
*   **Modular Architecture:** Designed with distinct components for transcription, audio processing, summarization, and vector storage, allowing for easy updates and integration of new models.
*   **Configurable Settings:** Utilizes a `settings.json` file for easy configuration of API keys, model choices, and other parameters.
*   **Local Vector Store:** Manages an efficient vector store to quickly retrieve relevant information for the RAG engine.
*   **Supports Various Audio Formats:** (Assumed, typically WAV, MP3, M4A are supported).

## Installation

Follow these steps to set up the project locally.

### Prerequisites

*   Python 3.9+
*   `pip` (Python package installer)

### Steps

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/Swain-Sanjay/meeting-summarizer-ai.git
    cd meeting-summarizer-ai
    ```

2.  **Create a Virtual Environment (Recommended):**
    ```bash
    python -m venv venv
    ```

3.  **Activate the Virtual Environment:**
    *   **On Windows:**
        ```bash
        .\venv\Scripts\activate
        ```
    *   **On macOS/Linux:**
        ```bash
        source venv/bin/activate
        ```

4.  **Install Dependencies:**
    ```bash
    pip install -r Requirements.txt
    ```

5.  **Configure API Keys and Settings:**
    *   Open `settings.json`.
    *   You will likely need API keys for services like OpenAI (for advanced transcription or LLM capabilities), or any other third-party services used by the `transcriber.py` or `rag_engine.py`.
    *   Update the placeholder values with your actual API keys and preferred model configurations.
    *   *Example `settings.json` (may vary based on actual implementation):*
        ```json
        {
          "OPENAI_API_KEY": "YOUR_OPENAI_API_KEY",
          "TRANSCRIPTION_MODEL": "whisper-large-v2",
          "LLM_MODEL": "gpt-4-turbo",
          "VECTOR_STORE_PATH": "./vector_store_data"
        }
        ```

## Usage

To use the meeting summarizer, you'll typically run the `main.py` script with your audio file.

1.  **Prepare your Audio File:**
    Place your audio file (e.g., `meeting.wav`, `lecture.mp3`) in a location accessible by the script. For testing, you can use the provided `How a Middle Class Boy Built NVIDIA From Nothing to $4 Trillion.wav` file.

2.  **Run the Summarizer:**
    ```bash
    python main.py <path_to_your_audio_file>
    ```
    Example:
    ```bash
    python main.py "How a Middle Class Boy Built NVIDIA From Nothing to $4 Trillion.wav"
    ```

3.  **Output:**
    The script will:
    *   Process the audio (chunking if necessary).
    *   Transcribe the audio.
    *   Ingest the transcription into the vector store.
    *   Generate a summary.
    *   Potentially allow for interactive Q&A based on the RAG engine.
    The summary and any generated answers will be printed to the console or saved to a specified output file (depending on implementation).
